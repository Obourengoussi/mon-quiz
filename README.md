# LE CÈDRE — Quiz d’informatique
## Leçon 1 : Le logiciel — CE1

Quiz HTML/CSS/JavaScript compatible avec GitHub Pages.

### Contenu
- 20 questions basées sur la leçon fournie « Le logiciel ».
- 30 minutes de temps maximum.
- Note sur 20.
- Correction détaillée à la fin.
- Clôture automatique à l'expiration du temps.
- Rapport des résultats par e-mail via FormSubmit.

### Publication GitHub Pages
1. Décompresser le dossier.
2. Mettre `index.html`, `style.css`, `script.js` et `config.js` dans le dépôt.
3. Activer GitHub Pages.
4. Lors du premier envoi FormSubmit, l'adresse de l'enseignant peut demander une confirmation.

### Important
`config.js` contient l'adresse e-mail destinée à recevoir les résultats. Aucun mot de passe ni clé secrète n'est stocké dans le site.
